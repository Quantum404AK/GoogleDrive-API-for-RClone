GoogleDrive API for RClone

This repository is a personal project created to support a private Google Drive setup for RClone.

The purpose of this project is to provide a simple API-based solution for a limited personal use case, focused on private Google Drive access and integration rather than any public or large-scale service.

This project is not intended for mass public usage, unrestricted public deployment, or commercial-scale distribution.

  • Purpose: personal Google Drive access for RClone
  • Scope: private and limited usage
  • Availability: not a public service
