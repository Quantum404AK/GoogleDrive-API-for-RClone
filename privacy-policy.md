# Privacy Policy

This project is a personal-use Google Drive API for RClone. It is intended for limited private use and is not designed for mass public usage or public-facing deployment.

The service is created to support the project owner’s own Google Drive and RClone workflow. Data handling is limited to the purpose of this project and is not intended to function as a broad public platform.

This document is intentionally brief and is not a full legal policy. The project is not meant to operate as a large-scale public service or a public API for general public access.
